# Sternendrift (Arbeitstitel)

Ein Raumschiffspiel für den Browser: Echtzeitkampf mit Pause, Energieverteilung und Pixel-Art.

## Spielen

Die aktuelle Version wird bei jeder Änderung automatisch über GitHub Pages veröffentlicht.

## Entwicklung

```bash
npm install
```

```bash
npm run dev
```

```bash
npm test
```
